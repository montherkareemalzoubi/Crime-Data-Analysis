# Crime-Data-Analysis
University project – data analysis, ML models, Power BI dashboards

---

##  How to Use the Project

1. Download the repository
2. Open `gppowerbi (2).pbix` using **Power BI Desktop**
3. Use the slicers on the left to filter by:
   - Year
   - Area
   - Hour
   - Crime Type
4. Explore interactive visuals and insights

---

##  Notes

- This project is developed for academic and analytical purposes.
- The dashboard is designed to support exploratory analysis and visualization, not real-time crime monitoring.
- Sensitive or private data has not been included.
